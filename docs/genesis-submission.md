# Squeek Farm: Hamster Wars

**Grow. Harvest. Defend. Expand.**

A cozy, fully playable farming and defense game for Squeekchain Genesis. Join Pip, a golden hamster farmer with a very big hat, and grow six illustrated crops in a sunny little paradise. Sell your harvest, unlock seeds, expand to eight plots, and build three automatic seed defenses to send the grumpy bandit Brutus packing.

Fresh, accepted hardware readings from Squeekchain’s public hamster-wheel API activate Squeek Sunshine, a capped 10% crop growth-speed bonus. If the wheel rests or the API is unavailable, the farm carries on at normal speed.

Original SVG artwork and animation, desktop and mobile controls, optional synthesized sound, a transparent local GOLD ledger, and browser saves with offline crop maturation. Free to play, with no wallet, real tokens, withdrawals, PvP, or offline theft.

The complete static IPFS-compatible export is in `dist/`. The hosting pipeline assigns the public URL after review.
